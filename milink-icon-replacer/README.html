MiLink 图标替换 ​

一个 LSPosed 模块，用于替换小米「融合设备中心」里各类设备卡片的图标。 可以替换控制中心下拉里的融合设备卡片，以及融合设备中心（CirculateWorldActivity）里的设备列表图标。

项值
包名com.milink.iconreplacer
版本2.8.8（versionCode 29）
适用HyperOS4
模块作用域com.android.systemui、com.milink.service
项目地址https://github.com/Yimo-Ye/milink-icon-replacer

一、安装与启用 ​

  1. 安装 MiLinkIconReplacer_v2.8.8-ui6.apk。

  2. 打开 LSPosed → 模块 → 找到「MiLink 图标替换器」→ 启用。

  3. 重要：点进模块的「作用域」，确认 两个 都被勾选：

    • ✅ com.android.systemui（系统界面，控制中心卡片）
    • ✅ com.milink.service（融合设备中心服务）

    只勾选后者时，控制中心下拉里的卡片不会被替换。

  4. 保存作用域后，重启 SystemUI（或直接软重启手机），让新的作用域生效。

如果替换无效，第一排查点永远是：作用域是否两个都勾了、重启过没有。

升级安装需使用同一签名（SHA-1 bf88ae36d1d449055976830a2d4f3c29d87d066c），否则 pm install -r 会失败。

二、模块页面 ​

模块自带一个设置页（打开模块图标即进入），提供：

  • 总开关：一键启用/停用全部替换（等价于 disable 文件）。
  • 模块状态：两张进程卡显示 SystemUI / MiLink 服务是否已加载 hook。
  • 图片目录：显示 override 实际路径，一键刷新列表。
  • 设备卡片列表：每张卡显示设备名、当前是否命中自定义图。
  • 使用说明：4 步上手 + 常见问题排查。
  • 状态栏与主题：跟随系统深浅色自动切换，状态栏图标（时间/电量/信号）自动反色。
  • 项目地址：页面底部可点击，跳转 GitHub 仓库。
  • 页脚版本号：v2.8.8。

页面只读取目录、不会修改你放进去的图片。

三、开关 ​

操作方式
关闭整个模块页面「总开关」关掉，或创建空文件 /sdcard/Download/MiLink_icons/disable
重新开启撤销上述操作

两个进程被 hook 时会先检查该文件，存在则直接跳过，不改任何图。改完需重启 SystemUI 与融合设备中心。

四、自定义图标 ​

放置路径 ​

/sdcard/Download/MiLink_icons/override/

模块页面的「图片目录」卡片里也会直接显示这个路径，可长按复制。

命名方式 ​

设备名（推荐，v2.8 起）

文件名（不含扩展名）与设备卡片上显示的名字一致即可，例如：

/sdcard/Download/MiLink_icons/override/REDMI Watch 5.webp
/sdcard/Download/MiLink_icons/override/小米手机.png

匹配时忽略大小写、空格和符号，所以 REDMIWatch5.webp、redmi_watch_5.webp 都能命中 REDMI Watch 5。

优先级 ​

  1. override/<设备名>.webp|png|jpg|jpeg
  2. APK 内置 assets/icon/<key>.webp
  3. 系统原图

生效方式 ​

改完图后重启 SystemUI 与融合设备中心（或重启手机）。模块内部有图片缓存，同一进程内不会重新读盘。

建议尺寸 ​

  • 建议 ≥ 512×512、透明背景的 PNG/WebP。

五、内置图标 ​

v2.8.8 起，APK 内只保留一张内置图：assets/icon/watch.webp（手表）。

其余内置图（phone / notebook / ipad / television / band / watch_square）已在 v2.8.8 移除。也就是说：

  • 你没在 override/ 里放图的设备，会回退到系统原图（或空）；
  • 想让某台设备显示自定义图，请自己在 override/ 里放同名文件。

APK 体积因此从约 993 KB 降到约 341 KB。

十、更新日志 ​

v2.8.8（versionCode 29） ​

  • 内置图标精简：assets/icon/ 只保留 watch.webp，移除 phone / notebook / ipad / television / band / watch_square 共 6 张。APK 约 993 KB → 341 KB。
  • 「使用说明 1. 放图片」补上实际目录路径 /sdcard/Download/MiLink_icons/override（独立一行显示）。
  • 「使用说明 2. 文件名就是设备名」举例改为 REDMI Watch 5.webp / REDMIWatch5.webp。

v2.8.7（versionCode 28） ​

  • 新增应用图标（@mipmap/ic_launcher，含 roundIcon，五密度适配）。
  • 页面底部新增项目地址链接，可点击跳转 GitHub；启动失败时降级为复制到剪贴板并 Toast 提示。

v2.8.6（versionCode 27） ​

  • 修复状态栏图标不反色：状态栏透明后系统默认按深色背景处理、使用白色图标，浅色主题下白图标压在浅色背景上不可见。
  • 新增 applySystemBarIcons(boolean dark)，双 API 兼容不同 OEM。

v2.8.5（versionCode 26）及更早 ​

  • 设备名匹配（忽略大小写/空格/符号）、RES_ALIAS 别名表、RES_EXCLUDE 非设备图标否决、 尺寸闸门从 intrinsic 改为布局尺寸（v2.6）、模块页面重构等。
